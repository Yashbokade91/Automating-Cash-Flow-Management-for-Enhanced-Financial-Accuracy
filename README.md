# Automating Cash Flow Management for Enhanced Financial Accuracy

## Overview
This repository contains the code and dataset for my Engineering Management Capstone Project. The project focuses on leveraging artificial intelligence and data analytics to automate cash flow management, ultimately improving financial forecasting accuracy and operational efficiency. 

## Repository Contents
* **`Capstone_AI_Forecast.py`**: The core Python script containing the data processing, AI modeling, and forecasting logic.
* **`Data_base.xlsx`**: A sample dataset utilized to train and test the forecasting models. 

## Project Objectives
* Automate the extraction and processing of financial data.
* Implement AI-driven forecasting models to predict future cash flows.
* Reduce manual errors and enhance the overall accuracy of financial reporting.

## Getting Started
### Prerequisites
To run the forecasting script, ensure you have Python installed along with the following libraries (you can install these via pip):
* `pandas`
* `numpy`
* `scikit-learn` (or other ML libraries utilized in the script)
* `openpyxl` (for reading Excel files)

### Usage
1. Clone this repository to your local machine.
2. Ensure `Data_base.xlsx` is in the same directory as the script.
3. Run `Capstone_AI_Forecast.py` to generate the automated cash flow predictions.
